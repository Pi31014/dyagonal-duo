# DIAGONAL DUO

4本脚キャラクターで相手をリングの外へ押し出す、スマートフォン対応の対戦ゲーム試作です。

## 今できること
- HTML Canvasで描くアリーナとキャラクター
- キー／画面ボタンで脚を蹴り、反動で移動
- 相手との衝突、リングアウト、60秒タイマー、スコア
- スマートフォンとPC向けの画面レイアウト

## 操作
- CYAN（左側）: W / A / S / D
- CORAL（右側）: 矢印キー
- 画面上のボタンでも操作できます
- R または「スタート / 再スタート」で再戦

## GitHub Pagesで公開する
1. リポジトリの **Settings** を開く
2. 左側の **Pages** を選ぶ
3. **Build and deployment** の **Source** を「Deploy from a branch」にする
4. Branchを **main**、フォルダーを **/(root)** にして **Save**
5. 公開処理が終わったら、Pages欄に表示されるURLを開く

## 現在の制限
これはまず操作感を試すためのローカル対戦プロトタイプです。複数端末をリアルタイムにつなぐオンライン通信、4人で各キャラクターの脚を分担する仕組み、部屋作成／参加コードはまだ実装していません。次の開発段階で追加します。
